# Инструмент визуализации графа зависимостей (Вариант №21)

## 1. Общее описание
Данный проект представляет собой CLI-приложение для анализа и визуализации графа зависимостей пакетов (формат npm / JavaScript) без использования сторонних менеджеров пакетов и библиотек для извлечения зависимостей.

На текущем этапе (Этап 1) реализован минимальный прототип с чтением и валидацией пользовательской конфигурации из файла формата TOML.

## 2. Описание всех функций и настроек
Приложение настраивается через конфигурационный файл формата TOML (по умолчанию `config.toml`).

### Поддерживаемые параметры:
* `package_name` (строка, не пустая) — имя анализируемого пакета.
* `repo_url_or_path` (строка, не пустая) — URL-адрес репозитория или путь к файлу тестового репозитория.
* `test_repo_mode` (логический тип `true`/`false`) — режим работы с тестовым репозиторием.
* `package_version` (строка, не пустая) — версия анализируемого пакета.
* `output_image` (строка, не пустая) — имя сгенерированного файла с изображением графа.
* `max_depth` (целое число `>= 0`) — максимальная глубина анализа зависимостей.
* `filter_substring` (строка, может быть пустой) — подстрока для фильтрации пакетов.

### Основные модули:
* `src/config_loader.py` — загрузка, парсинг TOML-файла и строгая валидация всех параметров.
* `src/cli.py` — интерфейс командной строки, обработка аргументов и вывод конфигурации.

## 3. Описание команд для сборки проекта и запуска тестов
Проект написан на языке Python (требуется версия **Python 3.11** или выше) и использует только стандартную библиотеку. Сборка не требуется.

### Запуск модульных тестов (проверка валидации всех параметров):
'python -m unittest discover -s tests -v'

## 4. Примеры использования
### Запуск с конфигурацией по умолчанию (config.toml):
На Linux / macOS:
'./run.sh'

На Windows:
'run.bat'

Или напрямую через Python:
'python -m src.cli -c config.toml'

Пример вывода программы (Этап 1):
'package_name = express
repo_url_or_path = https://registry.npmjs.org
test_repo_mode = False
package_version = 4.18.2
output_image = graph.png
max_depth = 3
filter_substring = test'

Пример вывода при ошибке в конфигурации:
'Configuration Error: Parameter 'max_depth' must be >= 0.'
